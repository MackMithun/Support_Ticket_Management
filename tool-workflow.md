# Tool Workflow

## Primary AI tool used
GitHub Copilot

## How project context is provided
Repository context, task requirements, and implementation constraints were provided directly in the workspace and through the exercise brief.

## Workflow used
- Requirement analysis and planning
- Implementation of backend models and controllers
- Frontend UI implementation
- Test creation and validation
- Reflection and documentation

## Information avoided sharing unnecessarily
Sensitive credentials and local machine-specific configuration were not included in prompts.
