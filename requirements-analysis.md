# Requirement Analysis

## Selected project option
Backend-heavy support ticket management system

## My understanding
The application should let a support team create tickets, review them in a dashboard, search and filter tickets, and move them through a controlled status lifecycle.

## Functional requirements
- Create tickets
- List and search tickets
- Update ticket status through valid transitions
- Reject invalid transitions
- Persist data for the local session

## Non-functional requirements
- Simple, organized UI
- Clear validation and error feedback
- Automated tests for the state machine
